# AIREACH 高价值客户猎手（每日哨兵 · 通用版）

面向外贸企业的 AIREACH 潜客巡检与高价值挖掘技能。**画像直接读取 AiReach 后台已填写的公司画像（client_profile_get / aw_icp_get），不做本地 ICP 收集**。每日检查新挖掘潜客是否符合后台画像，只推送不精准名单；从潜客池筛选高价值客户并生成可立即执行的跟进卡。

## 特性

- **画像来自 AiReach 后台**：技能不预置任何行业画像，运行时直接读 AiReach 后台的公司画像 + 理想客户画像（ICP），用于精准/不精准判定与高价值筛选。
- **每日合规检查**：只推送不精准客户（含不精准理由 / 所属图谱分支 / 排除建议），精准客户不打扰。
- **高价值跟进卡**：按后台画像标准筛选高价值客户，输出【下一步跟进建议】【推荐沟通渠道】【跟进话术】（地区语言 + 中文对照）。
- **强制 HTML 报告**：每次执行（手动或定时）都必须生成自包含 HTML 报告并交付，纯文本不能替代。
- **强制定时任务**：执行后必须确保存在每日 09:00 的定时任务（已存在则复用，不存在则新建），并询问使用者是否需要修改时间。

## 安装步骤

1. 依赖：需已安装并授权 **OKKI AiReach** 插件（潜客查询、画像接口均走 aireach-cli）。
2. 将本目录 `aireach-high-value-hunter/` 复制到技能安装目录（如 `agent-core/skills/` 下）。
3. 重启/刷新会话使技能生效。

## 首次使用

- 技能首次执行会自动调用 `client_profile_get` + `aw_icp_get` 读取 AiReach 后台画像，无需手动填本地配置。
- 后台画像为空/缺失时，技能会提示使用者去 AiReach 后台补齐，不编造、不回落本地。
- 画像任何变更在 AiReach 后台完成，技能只读、不提交（写操作必须使用者确认）。

## 日常使用

- 手动指令：「检查潜客」「推不精准」「找高价值客户」「出跟进话术」「潜客推送」「排除客户」。
- 定时任务：默认每日 09:00 自动执行（技能会确保该任务存在）。

## 注意事项

- 数据以 AIREACH 工具实拉为准，技能不编造公司名/联系人/邮箱/统计数字。
- ICP / 排除词等任何画像变更，均需使用者确认后才提交。
- 报告公司名称用纯文本，不生成含内部 task_id 的深链（避免暴露内部标识）。
