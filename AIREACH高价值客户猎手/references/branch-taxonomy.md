# 图谱分支分类表（reference）

用于每日合规检查时给不精准客户归类「所属图谱分支」，并给出对应排除建议。

> **重要**：下表仅为**结构示例（占位符）**，行业与分支内容不预置、不套用。实际分支分类应基于 **AiReach 后台画像**（`aw_icp_get.icp.commit_content` 的 wanted/unwanted 与 `client_profile_get.icp[].company_profile`），并随 AIREACH 挖掘结果动态建立与演进。

## 结构示例（占位符）

| 图谱分支 | 典型主营/类型 | 排除建议（ICP 排除词） |
|---|---|---|
| {目标行业}-{细分A} | {典型主营} | （保留） |
| {目标行业}-{细分B} | {典型主营} | （保留） |
| {目标行业}-渠道 | 贸易商、品牌商、分销商、线上平台 | （保留） |
| {非目标行业}-{类型} | {非目标主营} | 「{排除词}」 |

## 判定规则

1. 判定流程：识别潜客主营 → 对照 AiReach 后台画像（wanted/unwanted）→ 命中 wanted 且无 unwanted 冲突 = 精准；否则 = 不精准，归入最近似分支（或新建分支）→ 给出排除建议。
2. 排除词写入后台画像的 unwanted 前，必须经使用者确认（写操作 aw_icp_commit 需确认）。
3. 分支分类随挖掘结果演进，定期与使用者核对是否纳入排除词。

## 分支归类依据（确定性规则，保证输出稳定）

- 分支名称 = 「非目标行业」的行业名 + 客户类型，例如「电商建站服务商」「数字化服务商」「运动装备/服饰」。
- 同一客户只归入一个分支；优先按 `company_types` 主类型归类，其次按 `main_products` 首个词归类。
- 无法确定分支时，统一归入「其他非目标行业」，不臆造具体分支名。
