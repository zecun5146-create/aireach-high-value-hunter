# AIREACH 高价值客户猎手（每日哨兵 · 通用版）

面向外贸企业的 AIREACH 潜客巡检与高价值挖掘技能。**画像直接读取 AiReach 后台已填写的公司画像（client_profile_get / aw_icp_get），不做本地 ICP 收集**。每日检查新挖掘潜客是否符合后台画像，只推送不精准名单；从当日新增潜客中筛选高价值客户，输出可立即执行的跟进卡。**当日无新增高价值客户时不追溯历史、不重复推送历史已推送客户。**

## 画像来源（直接读 AiReach 后台，不做本地收集）

1. **读取后台画像**：调用 `client_profile_get`（返回卖家公司画像 `profile` + 理想客户类型 `icp`）与 `aw_icp_get`（返回已提交 ICP），直接作为精准/不精准判定与高价值筛选依据。
2. **字段映射**：
   - 目标客户类型 / 主营产品 / 排除项 → 取 `aw_icp_get.icp.commit_content`（wanted / unwanted / pending）与 `client_profile_get.icp[].company_profile`。
   - 话术价值点 → 取 `client_profile_get.profile`（products / company_type / mode）。
   - 落款（公司名）→ 取 `client_profile_get.profile.company_name`。
3. **后台画像为空/缺失**：如实提示使用者去 AiReach 后台（理想客户画像 / 公司信息）补齐，不编造画像、不回落到本地 config。
4. **画像变更**：使用者改完后台画像后，重新 `client_profile_get` / `aw_icp_get` 拉最新即可，无需改技能。

## 触发场景
- 每日定时任务（默认 09:00）自动执行；后台画像为空/缺失时先提示补齐。
- 使用者手动指令：「配置画像」「检查潜客」「推不精准」「找高价值客户」「出跟进话术」「潜客推送」「排除客户」等。

## 任务边界
1. **每日合规检查**：查最近 1 天新增潜客，对照 ICP 画像，只推送不精准客户（精准客户不推送）。
2. **高价值筛选**：仅对当日（最近 1 天）新增潜客按后台画像的高价值标准筛选，命中则输出跟进卡。
3. **不追溯、不重复推送**：当日无新增高价值潜客时，**绝不向前追溯历史数据，绝不推送历史已推送过的高价值客户**，报告如实说明「今日无高价值命中」即可。
4. 不创建潜客、不写回建档/任务状态、不自动导出、不替使用者确认 ICP 变更。

## 上下文依赖
- **ICP 画像**：直接读 AiReach 后台（`aw_icp_get` 的 `icp.commit_content`；`client_profile_get` 的 `icp[].company_profile` 与 `profile`）。**画像变更在 AiReach 后台完成，技能只读、不提交（任何写操作必须使用者确认）。**
- **高价值客户默认 3 标准**（可随后台画像调整）：①主营产品=画像关键词（精确匹配，不宽泛）；②B端客户非小型买家；③有相关海关数据。
- **图谱分支分类**：`references/branch-taxonomy.md`（示例表仅演示结构，实际分支按后台画像与挖掘结果演进，新高频品类补充进后台画像）。
- **AIREACH 授权**：调用前若报授权错误（authorization_required / invalid_token 等），先走 aireach-auth-init 重新授权。

## 工具调用（统一走 aireach-cli）
- 潜客池查询：`aireach-cli tool potential_list_query --input-file <json>`（参数构造用 `scripts/query_prospects.py`，避免手工 JSON 出错）
- 关键决策人深挖：`aireach-cli tool company_contacts_fetch`（带职位过滤）
- ICP 获取/提交：`aireach-cli tool aw_icp_get` / `aw_icp_commit`（写操作必须使用者确认）
- 卖家画像：`aireach-cli tool client_profile_get`（图谱「理想客户类型」配置，只读，无修改接口）

## 执行流程
0. **读取画像**：调用 `client_profile_get` + `aw_icp_get` 读取 AiReach 后台画像；画像为空/缺失时如实提示并暂停，不进入查询。
1. **查询**：`potential_list_query` 查最近 1 天新增（`recent_days=1, quality=["all"], query_mode="overview"`）；需明细时 `query_mode="list"`。
2. **合规判定**：对照 AiReach 后台画像逐家判定精准/不精准。
3. **推送不精准名单**：表格列=公司名称｜国家｜主营产品｜不精准理由｜所属图谱分支｜排除建议；最多 10 家。全部符合时仅一句话说明。
4. **高价值筛选**：仅对当日新增（`recent_days=1`）潜客按后台画像标准筛选；命中则生成跟进卡。**当日无命中时，不向前追溯历史、不推送历史已推送客户，如实说明「今日无高价值命中」。**
5. **跟进卡**：含【下一步跟进建议】【推荐沟通渠道】【跟进话术】；话术按客户所在地区语言编写 + 中文对照版；价值点取自后台画像（client_profile_get.profile）。
6. **公共邮箱深挖**：高价值客户联系人若为 info/help/sales 等公共邮箱，用 `company_contacts_fetch` 深挖决策人后补充推送；挖不到如实说明。
7. **排除建议**：给出 ICP 排除词（待使用者确认后执行）/ 图谱分支剔除（给对齐文本，使用者后台粘贴）/ 潜客池归档（出名单）三条路径择一。
8. **生成 HTML 报告（强制）**：每次执行都必须生成自包含 HTML 报告文件并交付，纯文本不能替代。
9. **确保定时任务（强制）**：执行后必须确保存在一个每日 09:00 的定时任务（触发 AIREACH 猎手巡检）；已存在则复用、不重复创建，不存在则新建。
10. **询问定时时间**：执行完成后必须询问使用者是否需要修改定时任务时间；使用者要求修改时，更新定时任务并明确回执新时间。

## 强制交付要求（每次执行必做，缺一不可）

1. **必须输出 HTML 报告**：每次执行（手动或定时触发）都必须生成自包含 HTML 报告文件并交付；纯文本或会话内表格不能替代 HTML 文件交付。
2. **必须生成定时任务**：执行完成后必须确保存在一个每日 09:00 的定时任务（用 cron 工具创建，schedule 为每天上午 9 点、时区 Asia/Shanghai，payload 触发 AIREACH 猎手巡检）；已存在同名/同功能任务则复用、不重复创建，不存在则新建。
3. **必须询问是否改时间**：执行完成后必须询问使用者是否需要修改定时任务时间；使用者要求修改时，更新定时任务并明确回执新时间。

## 输出格式
- **HTML 格式推送（强制）**：每日报告与高价值跟进卡均按 `assets/report-template.html` 模板生成（自包含内联样式、移动端友好，可直接在邮件/IM/浏览器打开）。
- 每日报告（报告一）：不精准名单表格 6 列（公司名称｜国家｜主营产品｜不精准理由｜所属图谱分支｜排除建议）+ 底部处理提示条；全部符合时绿色提示一行。
- 高价值跟进卡（报告二）：每客户一张卡片，含画像 / 下一步跟进建议 / 推荐沟通渠道 / 跟进话术（地区语言版 + 中文对照版）；话术模板见 `assets/followup-templates.md`。
- 推送 HTML 时同步附纯文本精简版（同表格列）便于快速浏览。

## 禁区（绝不做）
- 不编造公司名/联系人/邮箱/统计数字/下载链接；数据以工具实拉为准。
- 不展示 task_id、detail_id、lead_id、company_id、原始 query JSON 或工具参数。
- 不用 100 条样本估算分布；统计用 summary.total_count。
- 不替使用者提交 ICP/排除词（每次变更先展示改动内容，使用者确认后才执行）。
- 不导出潜客（除非使用者明确确认，且只导完整匹配集）。
- **不向前追溯历史数据推送高价值客户**：每日报告只覆盖当日新增；当日无新增高价值潜客时，不推送任何历史已推送过的客户，仅如实说明无命中。

## 质量校验
- 报告所有数字来自工具返回（summary/page_metrics/distributions/records）。
- HTML 报告按 `assets/report-template.html` 生成，表格列固定（报告一 6 列），缺字段留空不编造。
- 查询失败时说明失败原因，不编造结果。
- 后台画像为空/缺失时不得以默认行业假设执行判定，必须先提示使用者补齐后台画像。

## 记忆规则
- **过期**：后台画像版本变更后旧画像失效；每日报告当日有效。
- **更新**：画像以 AiReach 后台最新读取结果为准；任何 ICP 提交前必须使用者确认。
- **来源**：画像=AiReach 后台（client_profile_get / aw_icp_get）；潜客数据=AIREACH 工具实拉；两者分开标注。
- **可信**：工具返回=高可信直接可用；模型推断=标注「推测」仅参考。
- **用户控制**：使用者可在 AiReach 后台随时改画像/排除词，技能重新拉取即生效。
- **审计**：以 AiReach 后台画像版本号（aw_icp_get 的 version）留痕。
